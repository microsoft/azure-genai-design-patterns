# Changelog

All notable changes to this asset are documented here. This asset follows semantic versioning.

## 0.1.0 - 2026-10-20

- Initial preview release of the Microsoft 365 Integration with Azure Custom Engine Agent reference architecture.
- Added a surface decision matrix covering custom engine agents, declarative agents, Cowork, and Copilot Studio / Power Automate Workflows.
- Added an architecture deep dive covering the shared MCP tool layer, planner-and-specialist orchestration, proactive push, durable Azure Cosmos DB state, and side-effect action gates.
- Added an authentication and identity guide covering the five identity layers, SSO plus on-behalf-of (OBO) passthrough to downstream data platforms, and an ownership and offboarding checklist.
- Added ADR 0001 recording the surface and orchestration split.
